## Бэкенд (Cloudflare Worker + KV, бесплатно)
Конфиг — `wrangler.toml`, код — `worker/worker.js`, описание API — `docs/openapi.yaml`.
1. Cloudflare → Workers & Pages → Create → **Import a repository** → выбрать этот репозиторий (Build command пусто, Deploy command `npx wrangler deploy`).
2. KV-хранилище `DB` создаётся автоматически при деплое.
3. Worker → Settings → Variables and Secrets: добавить секрет `ADMIN_PASSWORD` (и `BOT_TOKEN`, `CHAT_ID` для Telegram).
4. Адрес Worker (`https://kyrgyz-trails-api.<поддомен>.workers.dev`) вписать в `js/config.js` → `API_URL`.

## Регистрация с подтверждением почты

Регистрация в «Дневнике путешественника» настоящая: аккаунт не активен, пока человек не нажмёт ссылку из письма.

- Адрес проверяется на сервере: формат, одноразовые домены (mailinator и т.п.), опечатки (`gmial.com`), и есть ли у домена почтовый сервер (DNS MX). Главная проверка — письмо.
- Пароль: от 8 символов, буквы и цифры. Хранится только хэш (PBKDF2 + соль).
- Письма (на 4 языках): подтверждение почты, приветствие после подтверждения, сброс пароля, уведомление о смене пароля.
- Защита: лимиты попыток на адрес и IP, одноразовые ссылки, неподтверждённые записи удаляются через 7 дней.
- Проверка: `node test/auth.test.mjs` (сервер) и `node test/e2e.mjs` (браузер).

### Подключение почты (бесплатно, один раз)

Без этого шага регистрация честно отвечает «не подключена отправка писем».

1. Зарегистрируйтесь на [brevo.com](https://www.brevo.com) (бесплатно, 300 писем в день, свой домен не нужен).
2. Senders, Domains & Dedicated IPs → Senders → добавьте свою почту (например Gmail) и подтвердите её письмом от Brevo.
3. SMTP & API → API Keys → создайте ключ и скопируйте его.
4. Cloudflare → Workers & Pages → kyrgyz-trails-api → Settings → Variables and Secrets, добавьте:
   - `BREVO_API_KEY` — тип **Secret**, значение ключа из шага 3;
   - `MAIL_FROM` — тип Text, подтверждённый адрес-отправитель из шага 2;
   - `MAIL_FROM_NAME` — по желанию, имя отправителя (по умолчанию Travel Horizon).
5. Сохраните и задеплойте. `SITE_URL` (адрес сайта для ссылок в письмах) уже задан в `wrangler.toml`.

## Что в админке
Заявки (канал связи, номер/ник как ссылка wa.me / t.me / tel:, язык общения, статус, сортировка), статистика, модерация отзывов гостей, главная и слайдшоу, история, области + легенды (картинки, факты, сезоны, точка на карте), туры, события, паспорт и QR, кыргызские слова, фото «Моя страна», путеводитель, соцсети, все надписи, цвета.
Русский текст переводится на en/zh/es автоматически; кнопка «Перевести все пустые» переводит всё сразу.

## Боевой режим
1. Cloudflare → Workers → код `worker/worker.js`; KV с именем `DB`; Workers AI с именем `AI` (для автоперевода).
2. Секреты: `ADMIN_PASSWORD`, `BOT_TOKEN`, `CHAT_ID` (новая заявка придёт вам в Telegram); `ALLOWED_ORIGIN` — адрес сайта.
3. Адрес Worker впишите в `js/config.js` → `API_URL`.
4. Автоответ клиенту в WhatsApp возможен только через платный WhatsApp Business API (Meta): задайте `WA_TOKEN`, `WA_PHONE_ID`, `WA_TEMPLATE`. Для Telegram и звонка автоответ не делается; вы сразу получаете уведомление.

## Дневник путешественника, баллы и подарки
Турист создаёт дневник (имя, почта, пароль), в поездке нажимает «Я здесь был!»: место, фото, заметка, область можно определить по GPS. За отметки: баллы, звания, подарки (настраиваются в админке → «Дневник и подарки»). В демо-режиме всё хранится в браузере; в боевом — Worker (`/api/auth`, `/api/diary`, пароли хешируются PBKDF2, фото лежат отдельными ключами KV). Список путешественников и их отметок — админка → «Путешественники».
**Честно:** отметки по GPS и вручную можно подделать. Перед скидкой проверяйте фото и даты. Восстановления пароля и подтверждения почты нет.

## Путеводитель: 2ГИС, банки, обмен валют
Плитки ведут на поиск 2gis.kg по выбранному городу (адреса городов правятся в админке и требуют проверки). Калькулятор валют берёт курс с open.er-api.com (бесплатно, со ссылкой на источник); официальный курс — ссылка на НБКР.

## Проверьте перед публикацией
Тексты легенд, фактов, дат и описаний туров — черновики. Даты фестивалей не заполнены намеренно. Тексты на китайском и испанском для легенд появятся после «Перевести все пустые». Ответы Барса на zh/es пока на английском. Карта схематичная. Погода берётся из Open-Meteo.
